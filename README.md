## Что внутри

| Раздел | Объём |

Тексты кодексов и постановлений Пленумов встроены внутрь: приложение работает без интернета. Клик по ссылке на статью открывает её текст в боковой панели. Прогресс сохраняется на устройстве и никуда не передаётся.

Формат экзамена, под который собран материал: один казус, четыре вопроса по ГП, ГПП, УП и УПП, 60 минут.

## Первый запуск

**Windows** покажет синее окно «Система Windows защитила ваш компьютер». Нажмите **Подробнее**, затем **Выполнить в любом случае**.

**macOS** заблокирует запуск по двойному клику. Нажмите по значку правой кнопкой, затем **Открыть**.

Так обе системы реагируют на любую программу без платного сертификата разработчика. Приложение не обращается к сети и не требует прав администратора.

**Android** попросит разрешить установку из этого источника — разрешение можно сразу отозвать после установки.
